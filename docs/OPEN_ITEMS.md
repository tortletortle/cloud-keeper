# V0.12.1 核心工程改造未闭环事项

这些事项没有被包装成“已完成”，需要下一轮在具备适当环境或证据后处理。

| 事项 | 当前状态 | 关闭条件 |
|---|---|---|
| 浏览器实际验收 | 由用户在本机完成；不作为本轮远端更新阻塞项 | 用户完成 Windows / Chrome 或 Edge 启动、交互、存档、弹窗和移动视口检查，并反馈问题 |
| GitHub 集成 | 正在通过独立工程分支提交；不直接覆盖 `main` | 工程分支包含完整源码与资源，CI 通过后提交 PR，由用户审查合并 |
| 美术素材 | 按用户说明，素材由 AI 生成；本轮不再向用户索取素材 | 在资产台账中记录生成来源与工具条款；不把用户提供的实拍素材混入生成素材 |
| 玩家存档迁移 | 当前没有外部玩家存档；不作为本轮工程交付前置条件 | 仅维护当前本机存档格式与异常保护；未来出现真实玩家存档后再增加迁移回归 |
| ESLint | 已增加 ESLint 9 Flat Config、固定执行版本和 lint 命令；CI 已纳入 lint | 在联网 CI 上验证实际规则输出，逐项修复错误级问题；警告级规则逐步收敛 |
| CSS 彻底收敛 | 已拆文件、清理已确认死规则、修复伪元素冲突和安全区覆盖；仍保留部分历史层叠覆盖 | 浏览器视觉回归后按组件重新整理，避免未经视觉验收的全局 CSS 重写 |
| 日数节奏 | 当前每 180 秒推进一天 | 通过游戏节奏测试决定最终一天长度和昼夜自动/手动规则 |
