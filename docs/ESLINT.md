# ESLint 规则

项目使用 ESLint 9 Flat Config，固定执行版本为 9.39.1，不依赖隐式的全局 ESLint 安装。

## 执行

```bash
npm run lint
```

脚本会提取 `index.html` 中的内联 JavaScript 到临时目录，并同时检查 ESLint 配置和提取脚本。临时文件在执行结束后清理，不修改游戏源文件。

## 规则分层

- **错误并阻断 CI：** 未定义变量、不可达代码、重复键/分支、非法正则、危险动态执行、调试器残留、稀疏数组、危险 finally、无效 typeof 等正确性和安全规则。
- **警告：** 未使用变量、隐式类型比较、代码块风格、尾随空格、重复空行、alert 和 const 优先级。
- **环境：** 同时声明浏览器与 Node.js 全局对象，避免把合法宿主 API 误报为未定义变量。

当前源代码仍是 V0.12 单文件形态，因此 lint 脚本先检查内联脚本。模块化工程的每个 JS/CJS 文件可直接纳入同一 Flat Config，无需另建规则体系。
